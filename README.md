# Automated Bank Reconciliation MIS

This project automates the reconciliation of bank transactions against company ledger records and produces a structured reconciliation output for MIS reporting.

The project uses Python for reconciliation, Excel for MIS reporting, Power BI for dashboard visualization, and PowerShell for refresh automation.

## How It Works

1. Bank statement and company ledger CSV files are provided in `data/input/`.
2. The Python reconciliation engine compares bank and ledger transactions using amount, date, and description matching logic.
3. Reconciliation results are generated in `data/output/reconciliation_results.csv`.
4. The Excel MIS dashboard uses the reconciliation output for reporting.
5. The Power BI dashboard uses the same reconciliation results for visualization.
6. PowerShell scripts automate the refresh workflow.

## First-Time Setup

1. Install Python 3.

2. From the project root, install the required dependencies:

```powershell
py -3 -m pip install -r requirements.txt
```

3. Ensure the required input CSV files are available in:

```text
data/input/
```

The Excel workbook is configured to use the project output folder. `scripts\configure_excel_query.ps1` is included as a repair/configuration script if the Excel query needs to be reconfigured.

## Refresh the Excel MIS

Run:

```powershell
.\scripts\refresh_all.ps1
```

The refresh workflow:

- Regenerates the reconciliation results
- Updates `data/output/reconciliation_results.csv`
- Refreshes the Excel data connection
- Recalculates the MIS dashboard
- Saves the updated workbook

Do not keep the Excel workbook open while the refresh script is running.

## Power BI

The Power BI dashboard is available in:

```text
dashboards/Automated_Bank_Reconciliation_Dashboard.pbix
```

The Power BI dashboard uses the reconciliation output generated by the Python reconciliation engine.

The `trigger_powerbi_refresh.ps1` script is included for Power BI Service refresh automation.

## Project Output

The reconciliation process produces a structured output containing:

- Bank transaction ID
- Ledger ID
- Bank date
- Ledger date
- Bank amount
- Ledger amount
- Amount difference
- Date difference
- Bank description
- Ledger description
- Reconciliation status

The output is designed to support transaction-level investigation as well as management-level MIS reporting.

## Project Objective

The objective of this project is to demonstrate an end-to-end automated bank reconciliation and MIS reporting workflow using Python, Excel, Power BI, and PowerShell.

The solution reduces manual reconciliation effort, standardizes exception identification, and provides management-ready reporting from a common reconciliation output.
